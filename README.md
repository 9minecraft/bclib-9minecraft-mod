## About this mod

BCLib 9minecraft Mod powers a popular series of dimension and nether overhaul mods. It works entirely behind the scenes to manage shared background systems like custom blocks, world data, and configuration files. You only need to install this library if another mod specifically asks for it, as it does not add any new items, blocks, or mobs on its own. Features: Safe World Updates: Includes a save-data fixer and migration system that keeps your old worlds loading safely across new updates.
